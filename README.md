# Graveyard Shift

Комедийная физическая песочница про скелетов на побегушках. Некромантка в депрессии, ей на всё плевать — поэтому её скелеты сами ходят за продуктами, убираются (в смысле громят) и решают простые бытовые задачи максимально сложными способами.

Вайб: городок как в «Симпсонах» / «Эдварде руки-ножницы», население потребительское как в Postal. Убивать никого нельзя. Скелеты бессмертны, но очень хрупкие.

## Ядро геймплея

Две механики:

1. **Скелет и его части.** Конечности отстёгиваются и используются отдельно: рука на радиоуправлении лезет в вентиляцию и открывает двери, череп можно закинуть в недоступное место — скелет соберётся там. Сильный удар (машина, падение, отдача ружья) — скелет рассыпается и ждёт кулдаун.
2. **Вселение в объекты (possession).** Единое интуитивное управление любым объектом: машина, тележка, конечность. Плюс «прилипание» к точкам взаимодействия (сесть на скамейку, залезть в машину).

Дизайн-принцип: простая задача — сложный способ. Скелету не продадут хлеб в магазине, но он может угнать машину и въехать в витрину.

## Стек

- **Godot 4.7.1** (GDScript, Jolt Physics)
- Ассеты: CC0-паки (Kenney, Quaternius) + процедурные модели
- Платформы: Windows (.exe), Web

## Запуск

Открыть проект в Godot 4.7+ и запустить, либо из консоли:

```
godot --path . 
```

## Статус

M1 готов: кладбище (задний двор особняка), двухэтажный готический особняк
(кухня, запертая кладовка, зал с камином и лестницей, спальня, библиотека)
и обучающая миссия «Рабочий день скелета»: встреча с хозяйкой у чёрного входа →
подмести кухню → помыть (или перебить) посуду → приготовить завтрак
(мука в запертой кладовке — рука лезет через вентиляцию) → подать завтрак,
не разбив. Дальше — M2: город, NPC, полиция, машины.

Тесты: `godot --headless --path . -- --selftest` — 13 сценарных проверок механик.
